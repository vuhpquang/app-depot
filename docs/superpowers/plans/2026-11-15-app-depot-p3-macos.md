# App Depot — Phase 3: macOS app — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A macOS "App Depot" (`com.vuhpquang.appdepot`, macOS 26+) that lists the owner's macOS apps from the live catalog, installs/updates one or all (verified, quitting and relaunching only the copy it replaces, never Wisp), shows What's New and history, checks in the background, reports events once paired, and updates itself from the catalog.

**Architecture:** Swift Package in `macos/` of `vuhpquang/app-depot` (like LaunchApp: `swift build/test`, `build.sh` → signed `.app` + DMG, `scripts/release.sh`). app-shell vendored as a git submodule at `macos/Vendor/app-shell` (`.package(path:)`) for About, Settings shell, What's New, Launch at login and self-update. app-shell gains (Task 1) a catalog update source and an "install another app" API. Pure logic in a `DepotCore` library target (no AppKit) with unit tests; app target `AppDepot` (SwiftUI + AppKit).

**Tech Stack:** Swift 6 language mode, `swift-tools-version:6.0`, macOS 26 (Liquid Glass ok), `@Observable` models, `URLSession` async, `CryptoKit` SHA-256, `Security` (`SecStaticCode`, `SecRequirement`), `UserNotifications`, SQLite via `import SQLite3` (system lib) for history/outbox, `os.Logger`.

**Spec:** `docs/superpowers/specs/2026-11-15-app-depot-design.md` §3 macOS, "Self-update", §1 API. Android app (`android/`) is the behavioural reference: same states, events, pairing, background policy (read `android/app/src/main/kotlin/com/vuhpquang/appdepot/core/*` for the pure rules).

## Global Constraints

- Identity: name **App Depot**, bundle id `com.vuhpquang.appdepot`, debug runs use their own defaults domain; accent depot green (same tokens as Android: `#2E7D5B` light / `#6FCF9F` dark) as one `DesignSystem/Theme.swift`; icon generated by `macos/scripts/make-icon.swift` (crate glyph), not hand-drawn PNGs.
- Version file `macos/VERSION` (start `0.1.0`); tags `macos-vX.Y.Z`; GitHub release `--latest=false`; asset `AppDepot-X.Y.Z-macos.zip` (zip of the `.app`, like ZenTask/Quickcast) — the catalog entry `app-depot-macos` uses assetPattern `^AppDepot-[0-9.]+-macos\.zip$`.
- Signing: self-signed identity **"App Depot Self-Signed"** created by `macos/scripts/make-signing-identity.sh` (copy of ZenTask's, backup in `~/.config/app-depot-macos-signing/`, never committed/printed). build.sh falls back to ad-hoc when the identity is missing; release.sh refuses to release unsigned/ad-hoc or with a different signer.
- Catalog: `GET https://vuhpquang.com/api/depot/catalog?platform=macos` (same JSON as Android; unknown keys ignored). Device + events API identical to Android with `platform: "macos"`. Event types exactly: `check, install, update, install_failed, open, crash, depot_started, self_update`.
- Verification before any install: size + SHA-256 match catalog; extracted bundle's `CFBundleIdentifier == appId`; `codesign --verify --deep --strict` passes; candidate satisfies the **installed copy's designated requirement** (update) or the catalog `signer` requirement string (first install; if `signer` is null → refuse first install with "This app can't be installed safely yet."). Never weaken this.
- Replacing an app: target = the installed copy's URL (`NSWorkspace.urlForApplication(withBundleIdentifier:)`), else `/Applications/<Name>.app`. Only the running instance whose `bundleURL` == target is asked to quit (`terminate()`, wait ≤ 10 s; if it refuses → state "Quit {name} to finish updating" and nothing replaced). Relaunch only if it was running, with catalog `relaunchArgs`. Install root overridable by env `APPDEPOT_INSTALL_ROOT` (tests/dev) — with it set, never touch `/Applications` or any app outside that root.
- **Wisp (`installMode selfUpdates`) is never installed, quit or replaced** — status + What's New + Open only. `none` (DevKit) → listed, no button. An installed version newer than the catalog → "Local build", never downgraded.
- Update conventions (`.claude/rules/app-shell.md`): checks 10 s after launch then every 6 h while "Check for updates automatically" (default on); "Install updates automatically" default off, disabled while auto-check is off; background checks never replace an Available/Failed state the user hasn't acted on and never show errors; background auto-install never quits a running app (it notifies instead) and never touches Wisp.
- App Depot's own update: via app-shell `Updater` with the new catalog source (slug `app-depot-macos`), so About/Updates pane/What's New are the shared ones. Settings keys for new apps: `UserDefaultsUpdateSettings()`.
- UI: main window (list + detail) and a menu bar extra (status, "Update all (n)", Open App Depot, Check for Updates…, Settings… ⌘,, Quit ⌘Q); app menu items per app-shell rule. Settings via `SettingsShell`: General (Launch at login [on by default for this background-capable app? → off by default, user choice], Connection/pairing), then Updates, then About. Native controls, grouped forms. Light + dark checked with a snapshot env var (`APPDEPOT_SNAPSHOT=/dir`) — the owner's installed apps are never launched/quit by tests.
- Copy: sentence case, verbs on buttons, errors say what to do, no exclamation marks.
- Commits: conventional, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, email `vuhpquang@gmail.com`; push app-depot `main` and app-shell `main` allowed; hub never pushed; hub pointer bumps + `npx gitnexus analyze` (hub root only).

## Review Focus

1. A running app being replaced refuses to quit → nothing replaced, clear message; other apps in Update all continue → test with a fake app controller (Task 4).
2. Candidate signed by a different identity, wrong bundle id, or tampered zip → refused, temp files removed, `install_failed` → tests in Task 1/4 (use real signed fixtures built at test time with `codesign -s -`, plus `/System/Applications/Calculator.app` for "anchor apple").
3. Wisp/DevKit/Local build never get an install path, including through Update all and background auto-install → tests in Task 3/6.
4. Catalog offline/malformed → last cached list + "Couldn't refresh" line → Task 3/5.
5. Self-update while other installs queued → self last; app-shell Updater only after the queue ends → Task 6.
