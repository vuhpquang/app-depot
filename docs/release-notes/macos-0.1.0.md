## What's new
- Install and update Padlet, LaunchApp, Quickcast and ZenTask in one place, from the menu bar or the window
- Update all: every app with a new version, one after another; an app that's open is quit, updated and reopened
- Every download is checked before it replaces anything: size, checksum, bundle and signature
- Wisp is shown with its notes but always updates itself; DevKit is listed until it has a release
- List or grid, search, sort, skip a version, move an app to the Trash, share a link
- Background checks tell you when a new version is available (installing on its own is off until you turn it on)
